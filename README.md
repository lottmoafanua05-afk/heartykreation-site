# Hearty Kreation

Single-file static homepage for heartykreation.com. Plain HTML with Tailwind CSS via CDN — no build step, no framework, no backend.

## Local preview

Open `index.html` directly in a browser, or serve it:

```
npx serve .
```

## Deploy

Pushing to `main` deploys automatically via the connected Vercel project.
